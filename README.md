# CAB32 Hash Functions

* Self-contained in a single C header file 
* Fast hash function was exceptional performance and competitive avalanche distribution
* Beats MurmurHash3 consistently in raw execution benchmarks from 5-25% with -O3/-Ofast 
* C99 with no dependencies, just compile it with any compliant compiler 
* Hashes are 32-bits long, great for embedded systems
